# Fichas técnicas de equipos nuevos — Tecnogrúas

Páginas públicas con la ficha técnica de cada equipo nuevo en venta. Las enlaza la
cotización de venta de equipo nuevo del CRM (foto pequeña + enlace + QR).

Una carpeta por modelo: `index.html`, `img/` y `descargas/`. Se sirve con GitHub Pages
en `https://grupocorpinsa.github.io/fichas/<modelo>/`.

Fuente de los datos: la ficha oficial del fabricante en español. Fuente de trabajo:
`AUTO18_CRM_CORPINSA/ficha_tecnica_equipos_nuevos/_web/`.
